# Project status

This is an independent pre-release maintained by Les., based on the MIT-licensed
Vituhlos integration at commit `67639e18d6d8595e87a31993802ae76745915a97`.

Automated integration and frontend tests cover the software behaviour. A pilot
installation has exercised wheel control of lights and media players. Device and
network behaviour can differ; Zigbee2MQTT group operation and additional hardware
combinations still need independent physical validation. See the
[hardware validation plan](docs/HARDWARE-VALIDATION.md).
